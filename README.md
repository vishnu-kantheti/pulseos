# 📖 Overview

PulseOS is an AI-powered restaurant management platform built to simplify restaurant operations through a single intelligent dashboard.

Instead of using multiple disconnected systems, PulseOS enables restaurant owners and managers to manage menus, customer orders, inventory, restaurant tables, reviews, and business insights from one centralized platform.

The project was developed as part of **Vibeathon 6.0**.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/vishnu-kantheti/pulseos.git

cd pulseos
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env.local` file.

```env
NEXT_PUBLIC_SUPABASE_URL=

NEXT_PUBLIC_SUPABASE_ANON_KEY=

OPENROUTER_API_KEY=
```

## Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
